Straight to the Point Archery

Project Overview

Straight to the Point Archery is a responsive website for an archery training centre. It provides information about the centre, its instructors, available classes, private lessons and contact details.

Features

Home page introducing the archery centre

Classes and training schedules

Instructor information

About the centre

Contact information

Responsive layout for desktop and mobile devices

Consistent colours and typography based on the style guide

Technologies Used

HTML5

CSS3

Google Fonts

GitHub Pages

How to View the Website

Visit the deployed GitHub Pages URL to browse the website. Alternatively, download the project files and open index.html in a web browser.

Credits and Acknowledgments
